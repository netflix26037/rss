# ReadSync — قارئ مواضيع شخصي يُزامن حالة القراءة بين أجهزتك

نسخة مبسّطة: لا حسابات، لا تسجيل — رمز دخول واحد فقط تعرفه أنت، تستخدمه من أي جهاز.

## التشغيل

```bash
npm install
npm start
```

رمز الدخول الحالي هو **5566** (مضبوط كافتراضي في الكود). لتغييره لاحقًا شغّل بدلاً من ذلك:

```bash
ACCESS_CODE="رمز-آخر" npm start
```

افتح على الكمبيوتر: `http://localhost:3000` وسجّل الدخول بالرمز.

## التشغيل من الجوال على نفس الشبكة

1. تأكد أن الكمبيوتر والجوال على نفس شبكة الواي فاي.
2. اعرف عنوان IP للكمبيوتر (ماك/لينكس: `ifconfig` أو `ip a` — ويندوز: `ipconfig`).
3. من متصفح الجوال افتح: `http://<عنوان-IP-للكمبيوتر>:3000`
4. سجّل الدخول بنفس رمز الدخول.

بما أن حالة "مقروء" مخزّنة على السيرفر (وليست في متصفح الجهاز)، أي مقال تفتحه أو تعلّمه كمقروء من أي جهاز يظهر مقروءً في الجهاز الآخر فورًا عند الضغط على "تحديث".

## كيف تعمل المزامنة

- عند الدخول بالرمز الصحيح، يحصل جهازك على توكن (JWT) يبقى صالحًا لمدة سنة ويُخزَّن محليًا في المتصفح.
- المصادر (Feeds) ومقالاتها وقائمة "مقروء" كلها مخزّنة في ملف واحد `data.json` على السيرفر — لا علاقة لها بجهاز بعينه.
- عند فتح `/api/articles`، يرجّع السيرفر كل مقال مع علامة `read: true/false` من نفس القائمة المشتركة.

## بنية المشروع

```
server.js      نقطة الدخول + كل الـ API
store.js       تخزين بسيط بملف JSON (data.json يُنشأ تلقائيًا)
public/index.html   الواجهة (صفحة واحدة، بدون فريمورك)
```

## أول 3 أشياء أقترح تطويرها بعد ذلك

1. **قاعدة بيانات حقيقية**: استبدل `store.js` بـ SQLite أو Postgres — ملف JSON مناسب للتجربة فقط.
2. **تحديث تلقائي للمصادر**: أضف مهمة مجدولة (`setInterval` أو cron) تجلب المصادر كل ساعة بدل الزر اليدوي.
3. **نشر دائم**: انشره على مضيف يبقى يعمل دومًا (Railway، Render، أو VPS بسيط) بدل الاعتماد على الشبكة المنزلية فقط — تجنّب "serverless" مثل Vercel ما لم تُبدّل التخزين لقاعدة بيانات خارجية، لأن نظام الملفات فيها لا يبقى بين الطلبات.

اقتراحات لاحقة أخرى: صفحة "قراءة لاحقًا" منفصلة، بحث ضمن المقالات، تمييز "مقروء" تلقائيًا عند التمرير، دعم تصنيفات للمصادر.
